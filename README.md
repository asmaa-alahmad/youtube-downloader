# YouTube Downloader

تطبيق ويب محلي لتنزيل فيديوهات YouTube باستخدام Python وFlask وyt-dlp.

## المميزات

- واجهة ويب بالوضع الداكن والفاتح.
- عرض تقدم التنزيل.
- عرض النسبة والسرعة والوقت المتبقي.
- حفظ الفيديوهات في مجلد Downloads/YouTube.
- زر لفتح مجلد التحميلات بعد اكتمال التنزيل.

## المتطلبات

- Windows
- Anaconda أو Python
- FFmpeg

## طريقة التشغيل

1. افتح Anaconda Prompt.
2. فعّل البيئة:

   ```bash
   conda activate ytdlp
   ```

3. انتقل إلى مجلد المشروع:

   ```bash
   cd C:\path\to\youtube-downloader
   ```

   استبدل المسار بمسار مجلد المشروع على جهازك.

4. ثبّت المكتبات:

   ```bash
   python -m pip install -r requirements.txt
   ```

5. شغّل التطبيق:

   ```bash
   python app.py
   ```

6. افتح المتصفح وانتقل إلى:

   http://127.0.0.1:5000

لإيقاف التطبيق، ارجع إلى نافذة Anaconda Prompt واضغط `Ctrl+C`.

## 10. تثبيت البيئة والمكتبات من الصفر على Windows

هذا القسم مخصص لمن يريد تشغيل التطبيق على جهاز جديد، حتى لو لم تكن لديه بيئة Python جاهزة.

### الخطوة الأولى: تثبيت Anaconda

1. افتح الموقع الرسمي: https://www.anaconda.com/download
2. نزّل نسخة Anaconda المناسبة لنظام Windows.
3. شغّل ملف التثبيت واتبع التعليمات حتى اكتمال التثبيت.
4. افتح **Anaconda Prompt** من قائمة Start.

للتحقق من تثبيت Conda، نفّذ:

```bash
conda --version
```

إذا ظهر رقم الإصدار، فهذا يعني أن Conda متاح للاستخدام.

### الخطوة الثانية: إنشاء بيئة مستقلة للمشروع

نفّذ الأمر التالي لإنشاء بيئة باسم `ytdlp` باستخدام Python 3.12:

```bash
conda create -n ytdlp python=3.12 -y
```

بعد اكتمال الإنشاء، فعّل البيئة:

```bash
conda activate ytdlp
```

يُفترض أن يظهر اسم البيئة `(ytdlp)` في بداية سطر الأوامر.

**ما فائدة البيئة؟**

البيئة المستقلة تفصل مكتبات هذا المشروع عن مكتبات المشاريع الأخرى، وتساعد على تجنب تعارض الإصدارات.

### الخطوة الثالثة: تنزيل المشروع من GitHub

إذا كان Git مثبتًا، انتقل إلى المجلد الذي تريد وضع المشروع داخله، ثم نفّذ:

```bash
git clone https://github.com/asmaa-alahmad/youtube-downloader.git
```


انتقل إلى مجلد المشروع:

```bash
cd youtube-downloader
```
### الخطوة الرابعة: تثبيت مكتبات Python

تأكد من تفعيل البيئة `ytdlp`، ثم نفّذ:

```bash
python -m pip install --upgrade pip
```

بعد ذلك ثبّت المكتبات:

```bash
python -m pip install -r requirements.txt
```

يحتوي ملف `requirements.txt` على المكتبات الأساسية:

- **Flask:** لإنشاء خادم الويب وعرض واجهة التطبيق.
- **yt-dlp:** لتنزيل الفيديوهات.
- **yt-dlp[default]:** لتثبيت الإضافات والتبعيات الافتراضية التي يوفرها المشروع.

للتحقق من تثبيت Flask وyt-dlp:

```bash
python -m pip show Flask
python -m pip show yt-dlp
```

### الخطوة الخامسة: تثبيت FFmpeg

يحتاج التطبيق إلى FFmpeg لدمج مسارات الفيديو والصوت عند الضرورة.

نفّذ الأمر التالي داخل Anaconda Prompt:

```bash
conda install -c conda-forge ffmpeg -y
```

بعد التثبيت، تحقق من عمله:

```bash
ffmpeg -version
```

إذا ظهرت معلومات الإصدار، فقد تم تثبيته بنجاح.

### الخطوة السادسة: تشغيل التطبيق

تأكد من أنك داخل مجلد المشروع وأن البيئة `ytdlp` مفعّلة، ثم شغّل:

```bash
python app.py
```

عندما يبدأ الخادم، افتح متصفح الإنترنت وانتقل إلى:

http://127.0.0.1:5000

ستظهر واجهة التطبيق، ويمكنك إدخال رابط فيديو والضغط على زر التنزيل.

اترك نافذة Anaconda Prompt مفتوحة أثناء الاستخدام؛ فهي تشغّل الخادم.

لإيقاف التطبيق، ارجع إلى نافذة الأوامر واضغط:

```text
Ctrl + C
```

### الخطوة السابعة: تشغيل التطبيق في المرات القادمة

بعد إغلاق التطبيق أو إعادة تشغيل الجهاز، لا تحتاج إلى إعادة تثبيت المكتبات. افتح Anaconda Prompt ونفّذ:

```bash
conda activate ytdlp
cd path\to\youtube-downloader
python app.py
```

استبدل `path\to\youtube-downloader` بمسار مجلد المشروع الفعلي.

ثم افتح:

http://127.0.0.1:5000

### حل المشكلات الشائعة

**1. ظهور رسالة `ModuleNotFoundError`**

تأكد من تفعيل البيئة الصحيحة، ثم أعد تثبيت المكتبات:

```bash
conda activate ytdlp
python -m pip install -r requirements.txt
```

**2. ظهور رسالة تفيد بعدم العثور على FFmpeg**

نفّذ:

```bash
conda activate ytdlp
conda install -c conda-forge ffmpeg -y
ffmpeg -version
```

**3. تعذر فتح الصفحة في المتصفح**

تأكد من أن الأمر `python app.py` ما زال يعمل، وأنه لا توجد رسالة خطأ في نافذة الأوامر.

**4. ظهور خطأ متعلق بـ yt-dlp أو YouTube**

حدّث المكتبة:

```bash
python -m pip install --upgrade "yt-dlp[default]"
```

إذا استمر الخطأ، اقرأ رسالة الخطأ كاملة؛ فقد تكون المشكلة مرتبطة بتغيّر متطلبات YouTube أو إعدادات الشبكة.
